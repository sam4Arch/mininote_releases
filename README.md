# MiniNote downloads

Downloads for **MiniNote**, a minimal, private-by-default notes app for Android and Windows.
This repository contains only the finished apps. Open **Releases** on the right and pick the latest version.

| File | For |
| --- | --- |
| `MiniNote-vX.Y.Z.apk` | Android |
| `MiniNote-Setup-X.Y.Z.exe` | Windows installer |
| `MiniNote-vX.Y.Z-windows-portable.zip` | Windows, no installation (unzip and run `mininote.exe`) |

## Installing

- **Android:** open the APK. Allow "Install unknown apps" when asked. If Play Protect warns, choose **More details, Install anyway**.
- **Windows:** run the installer. SmartScreen may warn because the app is not code-signed: **More info, Run anyway**.

MiniNote works fully offline. Sync and sharing are optional.
